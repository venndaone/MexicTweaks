## MEXXIC Tweaks v2.0.0

**Download:** `MexxicTweak100.exe` unten unter *Assets*

### Neu
- Premium-UI in Schwarz/Weiß mit Dashboard, Tweaks, Restore, System und Settings
- Deutsch & Englisch umschaltbar
- APPLY SELECTED mit Vorschau
- Vor jeder Änderung: Windows-Wiederherstellungspunkt + MEXXIC-Backup (Pflicht)
- Restore-Seite: jede Sicherung einzeln oder alles zurücksetzen
- Jeder Tweak wird nach dem Anwenden geprüft

### Installation
1. `MexxicTweak100.exe` herunterladen
2. Doppelklick → Admin-Abfrage mit **Ja** bestätigen
3. Passwort → **LOGIN** → Tweaks wählen → **APPLY SELECTED**

Backups aus v1.x werden automatisch übernommen.
